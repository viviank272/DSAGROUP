"For this assignment,we represented the TSP graph using an Adjacency matrix because its efficient for storing and       retreiving distances between cities.It is suitable for dense graphs like this one ,where most cities are connected
The TSP objective is to find the shortest possible route that visits each city exctly once and returns to the starting city.
 Assumptions made :the graph is undirected(traveling from city i to j is the same as traveling from city j to city i)and each edge has a positive weight distance

Classical TSP Solution
 As in the file tsp_nn.py,we implemented Nearest Neighbor Algorithm for its simplicity.This method starts from a given  city and repeatedly chooses the unvisited city
